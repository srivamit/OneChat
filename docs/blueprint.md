# **App Name**: OneChat

## Core Features:

- Real-time Chat Display: Display a real-time, one-to-one chat interface.
- Text Messaging: Enable users to send text messages to each other.
- User Status: Display the online/offline status of users.
- Smart Replies: Generate suggested quick reply options based on message content, providing convenient responses for the user; leverages a tool to determine when quick replies are likely to be useful.

## Style Guidelines:

- Primary color: Blue-grey (#7B8FA1), a muted tone that balances calmness and modernity.
- Background color: Black (#000000) for a sophisticated, high-contrast appearance.
- Accent color: Subtle Green (#98A680) to bring in a touch of nature and to highlight interactive elements.
- Font choice: 'Inter' (sans-serif) for both headings and body text, to give a clean, readable interface.
- Use simple, line-style icons in green-grey (#4B6A50) to maintain consistency and a modern aesthetic.
- Maintain a clean and organized layout with clearly defined sections for messages and user information.
- Incorporate subtle animations for message delivery and status changes to enhance user experience without distraction.
